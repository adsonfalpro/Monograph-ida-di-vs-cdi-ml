# Data

**This repository does not include any data, and it does not republish the ANBIMA series.** The IDA series are public, but you must
obtain them directly from ANBIMA (source below). The folder `data/` is ignored by Git (except this file), so the files you download and
everything derived from them stay on your machine.

## What you need

The pipeline reads two spreadsheets from `data/raw/` (create the folder):

| File | Content | Required |
|---|---|---|
| `data/raw/Dados-IDA.xls` | Daily series, 13 columns in this order: reference date, index level (*Número Índice*), IDA-DI return, duration, IPCA debenture return (in %), Ibovespa return (*BOVA*), CDI daily rate, % of CDI, excess, 60-day IDA, 60-day CDI, % of CDI (60 d), excess (60 d). From 2009-01-05 to 2025-11-19 (4,240 rows). The file is OOXML (xlsx) with an `.xls` extension; pandas reads it as is. | yes |
| `data/raw/Monografia - Dados.xlsx` | Derived base used in the original monograph (4,181 rows from 2009-03-31, 20 columns). Used only to reconcile the cleaned base with the original and by two tests. | optional |

**Source:** ANBIMA, *Índice de Debêntures ANBIMA (IDA)*, <https://www.anbima.com.br/pt_br/informacoes/ida.htm> (IDA-DI, duration and
IPCA debenture series; the CDI is the daily CDI rate). **Period:** 2009-01-05 to 2025-11-19, daily business days (4,240 rows).
**Columns:** the 13 listed above, in that order. Build the spreadsheet from the ANBIMA download with exactly these columns and this period. Column names and the cleaning applied (text values in the Ibovespa column, 4 days where the index level and the
return disagree, missing duration in the first 59 rows) are described in [`../docs/data_dictionary.md`](../docs/data_dictionary.md) and
[`../docs/data_quality_report.md`](../docs/data_quality_report.md).

## What the scripts create here

`src/` writes derived files to `data/processed/` (cleaned base, 10-day target, train/validation/test split, test predictions).
They are regenerated by the scripts in the order given in the root `README.md`; none of them is versioned.

Other files that contain the daily series and are therefore also left out of the repository:
`original/results/alertas_*_original.xlsx`, `outputs/backtest_check.xlsx` and `outputs/tables/target_comparison_by_window.csv`
(the last two are recreated by `src/backtest/excel_check.py` and `src/targets/compare_targets.py`).
